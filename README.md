**📚 Pustaka ini adalah klien tidak resmi untuk layanan pembuat musik generatif.** Isinya pembungkus tipis di atas model generasi musik, lengkap dengan pengunduh berkas audio. Selain dipakai sebagai modul, paket ini bisa dijalankan sebagai layanan web mandiri memakai kerangka API modern, baik di mesin lokal, di dalam kontainer, maupun di layanan hosting.

## ✨ Kemampuan
- **Klien Python 🐍**: memanggil layanan tanpa menulis ulang lapisan HTTP.
- **Pembuatan lagu 🎶**: memakai model generasi musik terbaru dari penyedia.
- **Ambil detail lagu lewat id 🎵**: menarik metadata lengkap sebuah karya.
- **Pengunduh audio 📥**: menyimpan hasil generasi langsung ke disk.
- **Mode layanan 🌐**: bisa dinaikkan sebagai endpoint REST.
- **Dokumentasi contoh 📚**: setiap fungsi disertai potongan kode.
- **Dukungan kontainer 🐳**: tersedia berkas kontainer siap pakai.
- **Publikasi ke platform ☁️**: cocok dipasang di layanan hosting terkelola.
